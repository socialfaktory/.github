# SocialFaktory

Run a brand's social media end to end: write the posts, make the videos, schedule and publish them on TikTok, Instagram, YouTube, X, LinkedIn, Facebook and Pinterest, then read the metrics back.

[![Available in the Claude directory](https://img.shields.io/badge/Claude-directory-D97757)](https://claude.ai/directory/connectors/socialfaktory)
[![Website](https://img.shields.io/badge/web-socialfaktory.com-111111)](https://www.socialfaktory.com)
[![Docs](https://img.shields.io/badge/docs-MCP-111111)](https://www.socialfaktory.com/docs/mcp)

## Use it from your AI assistant

| Where | How |
|---|---|
| Claude (web, desktop, mobile, Code) | [Add from the Claude directory](https://claude.ai/directory/connectors/socialfaktory) |
| ChatGPT, Cursor, Codex, any MCP client | Custom connector at `https://www.socialfaktory.com/mcp` ([setup](https://www.socialfaktory.com/docs/mcp)) |
| Gemini CLI | [socialfaktory-gemini-extension](https://github.com/socialfaktory/socialfaktory-gemini-extension) |

Sign in once with OAuth and choose what the assistant may do: read, spend credits, publish, for one brand or all, with a monthly credit cap. Revoke it any time.

## Repositories

- [socialfaktory-mcp](https://github.com/socialfaktory/socialfaktory-mcp): the MCP server listing, tools and setup for every client
- [socialfaktory-gemini-extension](https://github.com/socialfaktory/socialfaktory-gemini-extension): SocialFaktory for the Gemini CLI
